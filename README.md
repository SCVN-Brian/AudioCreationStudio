# Audio Creation Studio

A mini DAW inside the Unity Editor for game sound effects: a multitrack timeline (with slip / slide / roll / ripple / blade tools), a mixer and effects, procedural and AI (ElevenLabs) generation, seamless loops, variations, and WAV / AIFF / FLAC / MP3 / OGG export.

## Install (Unity 2022.3+)

Add this line to `Packages/manifest.json`:

```json
"com.supercent.audiocreationstudio": "https://github.com/SCVN-Brian/AudioCreationStudio.git?path=Assets/AudioCreationStudio#v1.3.0"
```

**User guide:** [AudioCreationStudio_Guide.html](Assets/AudioCreationStudio/Documentation/AudioCreationStudio_Guide.html) (a single self-contained page; download it and open it in a browser).

Full installation guide (Vietnamese): [Assets/AudioCreationStudio/README.md](Assets/AudioCreationStudio/README.md) · Changes: [CHANGELOG.md](Assets/AudioCreationStudio/CHANGELOG.md)

This repository is also the development project: open it in Unity 2022.3 to work on the package. The package itself lives in `Assets/AudioCreationStudio`.
